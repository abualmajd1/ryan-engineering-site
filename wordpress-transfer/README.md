# حزمة نقل صفحات هبوط مكتب ريان إلى WordPress

هذه الإضافة تعرض الصفحات الأربع كصفحات WordPress مستقلة، من دون إعادة بنائها داخل Elementor.

## المسارات

- `/lp/surveying-riyadh/`
- `/lp/engineering-consulting-riyadh/`
- `/lp/building-permits-riyadh/`
- `/sukuk/`

## التثبيت الأسهل

1. اضغط مجلد `ryan-landing-pages` بصيغة ZIP.
2. من لوحة WordPress افتح: **إضافات → أضف جديد → رفع إضافة**.
3. ارفع ملف ZIP ثم فعّل الإضافة.
4. أنشئ أربع صفحات WordPress عادية، واترك محتوى الصفحة فارغاً، واستخدم العناوين والـ Slugs المذكورة أعلاه.
5. لا تستخدم Elementor داخل هذه الصفحات؛ الإضافة تعرض التصميم تلقائياً عند فتح المسار.
6. من **الإعدادات → Ryan Landing Pages** أضف GTM ID. إذا لم تستخدم GTM، يمكنك إضافة GA4 ID مباشرة.
7. امسح كاش LiteSpeed، ثم اختبر المسارات على الهاتف والكمبيوتر.

> ملاحظة مهمة: النسخة الحالية تستخدم قالب HTML مستقلاً لصفحات الهبوط، ولا تستدعي `wp_head()` أو `wp_footer()` الخاصة بقالب Finovate/Elementor؛ هذا يمنع تعارض CSS والقوائم والأزرار مع التصميم.

## إعداد التتبع

الأفضل إدخال `GTM-XXXXXXX` فقط في الإضافة، ثم إنشاء GA4 Tag داخل GTM باستخدام معرف `G-XXXXXXXXXX`. الإضافة ترسل أحداث `dataLayer` مثل:

- `landing_page_view`
- `landing_form_submit`
- `phone_click`
- `whatsapp_click`

لا تضع معرفات وهمية داخل الكود. استخدم المعرفات الفعلية لحساب الشركة.

## ملاحظات مهمة

- خذ نسخة احتياطية من WordPress قبل التفعيل.
- لا تحذف صفحات الموقع الحالية.
- يجب أن تكون Slugs مطابقة تماماً حتى تعمل الصفحات الأربع.
- إذا كان هناك إضافة حماية تمنع رفع ZIP كبير، ارفع المجلد عبر File Manager إلى `wp-content/plugins/` ثم فعّله من لوحة WordPress.
- بعد التثبيت افحص Network للتأكد من أن الملفات تُحمّل من `/wp-content/plugins/ryan-landing-pages/assets/` بدون 404.
